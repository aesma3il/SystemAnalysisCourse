# تأجير السيارة

أجر السيارة: أكراها، ومكّن غيره من الانتفاع منها مقابل أجرة معينة.

## الأسئلة الأساسية

- من الذي أجّر؟
- من الذي استأجر؟
- ما الذي تم تأجيره؟
- مقابل ماذا تم تأجيره؟
- ما الذي يثبت أن فلان قام بتأجير السيارة إلى فلان؟
- هل المؤجر استلم الأجرة؟
- هل المستأجر دفع الإيجار؟
- هل المستأجر استلم السيارة؟
- هل المستأجر أعاد السيارة؟

# الإيجار

## كم يدفع إيجار؟

- قيمة الإيجار اليومية
- قيمة الإيجار الأسبوعية
- قيمة الإيجار الشهرية

## كيف يتم حساب الإيجار؟

- حسب عدد الأيام
- حسب عدد الساعات
- حسب المسافة المقطوعة
- حسب نوع السيارة
- حسب مدة التأجير
- مع وجود خصومات أو غرامات
